# 特殊作业智能报警模块｜原型落地规格说明书（AI/开发专用）

## 0\. 文档说明（原型落地专用）

本文档为**可直接产出UI原型、交互逻辑、代码逻辑、测试用例**的标准化落地文档。无模糊业务描述，全部为：状态定义、判定公式、交互行为、页面模块、字段、触发时机、销号逻辑、权限、弹窗规则。

适配范围：动火作业、受限空间作业、爆炸危险场所临时用电作业告警（对应规范5\.9\.1\-5\.9\.10）

核心模型：**可配置规则引擎 \+ 事件即时校验 \+ 定时轮询校验 \+ 统一告警闭环工单**

## 1\. 基础通用定义（全局统一，所有页面生效）

### 1\.1 作业状态枚举（校验前置条件）

告警仅在以下3种作业状态触发：待开工、作业进行中、作业中断

作业状态为：已完工、已作废、已关闭 → **停止所有告警校验**

### 1\.2 时间冻结规则（强制逻辑）

作业状态 = 作业中断时，冻结以下所有计时：

- 受限空间2小时气体检测倒计时

- 作业票有效期超时倒计时

- 审批超时倒计时

作业状态恢复为【作业进行中】，所有计时**重新启动计算**。

### 1\.3 告警状态枚举（原型必须做）

待处置、处置中、已复核闭环、已自动销号、已失效

### 1\.4 告警等级枚举（后台可配置）

- 一级预警（提示）：仅消息推送，不拦截任何操作

- 二级告警（一般）：可配置禁止新增作业记录/禁止开工

- 三级告警（严重）：弹窗强提醒、可配置强制暂停作业、禁止完工闭环

### 1\.5 两种校验模式（底层固定逻辑）

- 事件触发：数据新增/保存/状态变更**瞬间校验**（1s内响应）

- 定时轮询：系统后台1分钟一次扫描，校验所有超时类规则

### 1\.6 两类销号逻辑（固定）

- 自动销号：补录合规数据后，系统自动比对通过，即时销号

- 人工闭环：用户提交处置\+图片佐证 → 管理员复核通过 → 闭环销号

### 1\.7 离线适配交互（原型必备）

移动端离线状态下：缓存所有操作、缓存校验状态；联网瞬间自动同步数据、批量触发告警、更新所有页面状态。

## 2\. 后台配置中心原型规格（可配置参数全部清单）

页面名称：特殊作业告警规则配置

权限：仅超级管理员、安全管理员可见可编辑

页面模块：规则列表、参数配置、推送配置、开关配置、操作日志

### 2\.1 每条规则统一配置字段（9条规则共用一套配置）

- 规则名称、关联国标条款、规则启用开关

- 阈值参数（数值输入框，支持自定义）

- 告警等级下拉选择（一/二/三级）

- 是否开启作业拦截（是/否）

- 推送对象配置（岗位/角色/指定人员）

- 推送渠道勾选（APP消息/站内信/大屏）

### 2\.2 可自定义阈值清单（原型固定配置项）

- 特级/一级动火中断超时阈值（默认30min）

- 二级动火/受限空间中断超时阈值（默认60min）

- 受限空间连续检测周期（默认2h）

- 作业审批超时时限（默认自定义）

- 作业票到期预警提前时长（默认30min）

- 现场定位偏移阈值（距离范围）

## 3\. 九大告警规则｜原型精准判定逻辑（可直接写代码/做交互）

### 3\.1 规则1：作业中断超时未气体分析（5\.9\.1）

**触发时机**：定时轮询

**判定公式**：

if 作业状态=作业中断 \&\& 作业类型=特级/一级动火 \&\& \(当前时间\-中断时间\)\>配置阈值 \&\& 中断时段无新气体记录 → 触发告警

if 作业状态=作业中断 \&\& 作业类型=二级动火/受限空间 \&\& \(当前时间\-中断时间\)\>配置阈值 \&\& 中断时段无新气体记录 → 触发告警

**自动销号条件**：新增一条关联本票的合规气体分析记录

**页面交互**：作业票顶部红字提示条，展示“作业中断超时未复检气体”

### 3\.2 规则2：跨日作业每日开工未气体分析（5\.9\.2）

**触发时机**：事件触发（每日首次操作作业）\+ 定时校验

**适用作业**：二级动火、爆危场所临时用电

**判定公式**：作业跨自然日 \&\& 当日0点后无任意一条气体检测记录 → 触发告警

**自动销号条件**：补录当日气体检测记录

### 3\.3 规则3：气体分析值不达标（5\.9\.3）

**触发时机**：事件触发（保存气体记录瞬间）

**适用作业**：动火、受限空间、爆危临时用电

**判定公式**：氧含量/可燃气体/有毒气体任意指标超出对应作业类型阈值区间 → 触发三级严重告警

**自动销号条件**：新增一条全部指标合规的气体记录

**强制交互**：保存不合格数据立即弹窗告警，提示“气体浓度不达标，禁止作业”

### 3\.4 规则4：受限空间超2h未检测（5\.9\.4）

**触发时机**：定时轮询

**判定公式**：作业状态=进行中 \&\& 非中断状态 \&\&（当前时间\-最近气体记录时间）\>配置2h阈值 → 触发告警

**自动销号条件**：新增气体检测记录

### 3\.5 规则5：作业票有效期超时（5\.9\.5）

**触发时机**：定时轮询

**判定公式**：作业状态=待开工/进行中 \&\& 当前时间\>计划结束时间 → 超时告警；支持提前预警

**销号条件**：作业完工/作废/延期审批通过

### 3\.6 规则6：审批人/监护人不在现场（5\.9\.6）

**触发时机**：事件触发\+定时轮询

**子规则1：审批非现场签批**：审批操作无现场人脸/定位、定位偏移超出阈值 → 触发告警

**子规则2：监护人离岗**：作业进行中，监护人超时未打卡/定位偏离 → 触发告警

**销号方式**：人工处置\+复核闭环（不自动销号）

### 3\.7 规则7：特种作业人员资质不满足（5\.9\.7）

**触发时机**：事件触发（新增人员、保存作业票、提交审批）

**判定维度（满足任意一条即告警）**：

- 无对应作业特种证书

- 证书已过期

- 证书类型与当前作业不匹配

- 专项安全培训过期

**自动销号**：替换合规人员/更新有效资质后重新校验通过

### 3\.8 规则8：交叉作业票未办全/未关联（5\.9\.8）

**触发时机**：事件触发（保存作业类型、提交开工）

**判定公式**：勾选作业类型≥2种 \&\& 对应作业票未全部创建 / 未完成跨票关联 → 触发告警并禁止开工

**销号条件**：补齐所有作业票 \+ 完成关联 \+ 全部票据审批通过

### 3\.9 规则9：作业票超时未审批（5\.9\.9）

**触发时机**：定时轮询

**判定公式**：作业票状态=待审批 \&\&（当前时间\-提交时间）\>配置审批时限 → 触发逐级推送告警

**自动销号**：审批通过/驳回

## 4\. 告警闭环工单原型规格（统一模板，所有告警通用）

所有告警统一生成【告警处置工单】，页面字段完全统一

### 4\.1 工单固定字段

- 告警编号、关联作业票号、触发规则条款、告警等级

- 触发时间、作业地点、作业类型

- 触发原因（系统自动生成文本，不可编辑）

- 处置人、处置时间、处置说明（手动输入）

- 现场佐证图片（多图上传）

- 复核人、复核时间、复核结果（通过/驳回）

### 4\.2 闭环流程（原型固定流转）

告警生成 → 推送待办 → 处置人提交整改 → 复核人审核 → 闭环销号/驳回重改

**数据约束**：所有告警记录、工单记录永久存档，禁止删除、篡改

## 5\. 前端页面原型规格（PC\+移动端）

### 5\.1 PC端\-告警中心页面

模块1：数据统计卡片（待处置、处置中、已闭环、超时告警）

模块2：筛选栏（作业类型、告警等级、时间范围、条款类型、作业地点）

模块3：告警列表（每条展示：等级、票号、条款、状态、触发时间、操作）

模块4：告警详情页（完整日志\+原始数据\+工单流转记录）

模块5：导出功能（Excel/PDF台账）

### 5\.2 移动端页面

消息推送弹窗、告警待办列表、快速处置页、复核页

点击消息直接跳转对应工单详情

### 5\.3 作业票内嵌组件（核心原型）

作业票顶部常驻**告警提示条**：红色展示当前未闭环告警数量及简要原因

高等级告警：开工按钮、完工按钮置灰锁定，整改闭环后自动解锁

## 6\. 权限原型规则（固定）

- 规则配置：仅超管/安全管理员

- 告警处置：作业负责人、监护人

- 告警复核：属地管理员、安全管理员

- 日志查看：全员可看台账，仅管理员可看操作日志

## 7\. 交互拦截规则（原型强约束）

- 存在未闭环三级严重告警：禁止作业完工闭环、禁止结票

- 交叉作业未关联票据：禁止开工

- 人员资质违规：禁止提交作业票/禁止开工

- 气体严重超标：实时弹窗拦截，提示禁止作业
